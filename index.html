📊 Diapositiva 3: Brain Spark

1. 💬 Pide a XOLO que te ayude a crear:

"Ayúdame a forjar una herramienta para un agente: elegiré una capacidad (traducir texto, precio de acción, etc.). Con Vibe Coding, define el propósito, entradas, salidas y posibles abusos. Luego guíame a crear: (1) la función Python y (2) el esquema JSON que la etiqueta para un LLM. Ejecución: entrega ambos artefactos (código + JSON) y una nota breve de pruebas con 2 ejemplos de entrada/salida."

2. 🔬 Experimenta y descubre con tu programa:

  • ¿La IA elige la herramienta correcta cuando le das una instrucción clara?
  • ¿Qué pasa si dejas una descripción de parámetro vacía o muy vaga?
  • ¿Funciona igual la herramienta con un número vs. un texto si el JSON pide un tipo específico?
  • ¿Cómo ayuda el esquema JSON a que la interfaz humano-IA sea más segura y menos ambigua?
  • ¿Por qué es importante definir límites de seguridad desde el diseño de la función?

¡Es hora de crear! Vamos a pasar de la teoría a la acción. Imaginen que su agente necesita una habilidad especial, como calcular impuestos o traducir jerga técnica. Usaremos el flujo: idear la capacidad, definir su VIBE, crear el código en Python y luego el esquema JSON que le dice a la IA cómo usarlo. Por ejemplo, podrían crear una herramienta que consulte el clima y decida qué ropa recomendar basándose en datos reales. Recuerden revisar las preguntas de experimentación para ver si su herramienta es robusta. Si tienen errores o dudas, pregúntenle a XOLO, él los ayudará a depurar y perfeccionar su herramienta. ¡A construir!
